# Weather Checker app
A Weather checker app that tells the temperature, what it feel like and the weather description of the city searched made with React, Vite and CSS

## Features
- Brings weather info about the city searched
- Add or remove a city from your favorites city section(side-menu)
- Check for duplicates inside favorites
- Toast Notification that give instant feedback when updating city status
- Data persists with localStorage

## What I Learned
- Api fetching and how to handle promises in react
- Error handling
- Dynamic feedback(notification) handling
- Learned more about state updating functions

## Tech Stack
- React
- Vite
- CSS
